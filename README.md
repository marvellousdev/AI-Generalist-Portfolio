# AI Generalist Evaluation Portfolio

An independent practice portfolio for **Afe Marvellous Ifedolapo**, demonstrating how to evaluate AI-generated responses on accuracy, instruction following, reasoning, and clarity.

## What's inside
- `index.html` — landing page, work samples, and scoring-lab interface
- `style.css` — responsive dark-theme design
- `script.js` — example switching, manual scoring, and CSV export
- `.nojekyll` — helps GitHub Pages publish the static site without Jekyll processing

Three evaluation examples are **synthetic exercises**, not paid work experience, independent certifications, actual Mercor tasks, or verified real-world client projects.

## Preview locally
Double-click `index.html` in Windows File Explorer. No installation, server, or API key is required.

## Get a public link using GitHub Pages
1. Log in to GitHub. Create a new **public** repository named `ai-generalist-portfolio` (or use an existing one).
2. Upload `index.html`, `style.css`, `script.js`, and `.nojekyll` to the repository's **root** on the `main` branch. You can also upload this ZIP's extracted files using **Add file → Upload files**.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**. Select **main**, choose **/(root)**, and click **Save**.
5. Once GitHub finishes publishing, use the **Visit site** button shown in **Settings → Pages**.
6. Copy that actual, working public HTTPS address into Mercor's portfolio/website link field.

For a project repository named `ai-generalist-portfolio`, GitHub Pages usually produces an address in the format:
`https://YOUR_USERNAME.github.io/ai-generalist-portfolio/`
Replace YOUR_USERNAME with the account that owns the repository. The address does not become active until the repository is published. Do not paste a guessed URL into Mercor.
